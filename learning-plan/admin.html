5. 저장

저장하면 빌더의 템플릿 목록에 즉시 나타납니다 — 승인 절차 없음, 생성·수정 이력은 자동 기록

4. 학기 배치 미리보기

엑셀의 학기 열대로 배치된 결과 — 저장 후 빌더에서 학생별로 조정합니다
엑셀 업로드는 이관·최초 등록용입니다. 한 번 등록해 템플릿으로 남기면 다음부터는 빌더에서 불러다 쓰므로 업로드가 다시 필요하지 않습니다 — 엑셀 작업이 상시 입력 수단으로 되돌아오지 않게 하는 것이 이 화면의 목적입니다.
