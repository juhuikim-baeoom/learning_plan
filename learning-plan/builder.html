1단계 범위 - 기준 마스터 자동 검증(2단계) · 결제 연결/쿠폰(3단계) · 이정표(추후) 미포함
기획설명 학습설계 툴 - 세로 3단 구조

전제

  • 엑셀 스프레드시트 워크플로 대체 - 설계·발송·보관을 구조화된 데이터로
  • 자사 이수는 LMS 자동 조회 · 타기관(전적대)만 엑셀 업로드 - 중복 입력 차단
  • 입력 자동화 ≠ 인정 자동화 - 업로드는 행만 채우고, 인정 판단은 담당자 몫

화면 순서 기이수 현황 → 이수구분 집계표 → 수강 계획

  • 기이수 현황(과거) - 미분류를 기본 탭으로 두어 처리할 것부터 눈에 들어오게
  • 이수구분 집계표(판정) - 과거(인정)와 미래(배치)를 합산해 요건 충족을 판정하는 유일한 지점
  • 집계표를 위아래 어느 카드에 붙여도 한쪽 편이 되므로 가운데 경계에 독립 카드로 분리
  • 수강 계획(미래) - 인정된 과목은 회색 체크로 자리를 남겨 배치에 "구멍"이 안 보이게

자격증 / 학위 화면 구조는 같고 이수구분만 교체되는 축

  • 학위 - 전필 · 전선 · 교양 · 일선 4분류
  • 자격증 - 필수 · 선택 2분류. 필수 10과목 30학점 + 선택 7과목 21학점 (2020 개정 17과목 기준)
  • 집계표의 예정 열은 취득예정 자격증의 조건부 학점 - 확정분(인정)과 섞이지 않게 분리 표기
미확정 - 집계표 상단 고정(sticky) 여부. 수강신청 좌측바와 같은 이유로 보류 중이며, 화면 전체가 함께 스크롤되는 쪽이 현재 기준선. 레이아웃 A(집계 고정+탭) · B(좌우 2분할)은 코드만 남고 전환 UI 미노출.
