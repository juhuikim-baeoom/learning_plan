## 1. 프로젝트 개요

### 1-1. 문제 정의
- 보유학점·자격증 보유 학생 맞춤 설계 = 상담사가 개인 PC 엑셀로 표 작성 → 에디터 붙여넣기
- **모바일에서 표 깨짐** → 학생이 설계를 확인 불가
- 설계가 자유 텍스트(표)로 저장되어 검증·재사용·이력 관리·AI 연계 전부 불가
- 상담사별 인정 기준 편차, 과목 변경 시 수동 재작성

### 1-2. 해결 방향
- 표 그리기 → **과목별 상태 지정(구조화 데이터)** 으로 전환
- 데이터로 저장 → PC/모바일 자동 재렌더링, 검증·스냅샷·템플릿·결제 연동이 동일 데이터 위에서 동작
- 에디터는 코멘트 등 자유 서술 영역에만 사용

### 1-3. 목표
1. 엑셀 수작업 제거 (경로 B 맞춤 설계 표준 도구)
2. 모바일 표 깨짐 0건
3. 발송 전 자격취득 기준 자동 검증 → 상담사 간 편차 축소
4. 설계 → 결제(전체/부분) 무단절 연결
5. 스냅샷·이력 체계화 → 민원·분쟁 근거 확보

**확정 사항**
- **학습설계 타입 3종**
  - `제안` — 목표·학력만으로 일반안 제공, 패키지 거의 그대로 템플릿화, 야간·주말 자동
  - `설계` — 상세 이수내역(전적대·자격증) 기반 맞춤, 패키지를 템플릿으로 불러와 가공

- **유료 에디터 도입 불필요** — 엑셀 표는 고정폭 HTML이라 에디터 품질과 무관하게 모바일 깨짐 해소 불가 (연 500~600만원 절감 근거)
- **패키지 → 템플릿 변환** = 없는 정보 생성이 아니라 기존 패키지 데이터(학기-차수별 과목·이수구분·가격) 읽어오기
  - 학위과정: 전필/전선/일선/교양 거의 1:1
  - 자격증과정: 과정별 이수구분 매핑표 필요
  - 빌더 1단계 **선행 작업** (없으면 불러올 템플릿 자체가 없음)

### 2026.06.12 — 데이터 모델 논의

  - 자격증: 과정별 체계 상이 (사복 필수/선택, 건강가정사 핵심/기초/상담, 보육교사 필수/기초 등)

## 3. 주제별 확정 결정사항

### 3-1. 상태 정의
**설계 상태**
```
임시저장 ──검증 통과──▶ 발송 완료 ──변경──▶ 재설계(새 임시저장 v+1)
(수정 자유)            (스냅샷 고정)         (기존 버전 불변 보존)
(학생 비노출)          (학생 노출)
```
- 스냅샷 고정은 **발송 시점에만**
- 발송분 수정 불가 → 반드시 새 버전 (원데이터 보존 = 분쟁 방지 원칙)

**기이수 인정 상태 3종**: 미분류(주황) / 인정(파랑) / 미인정(회색)

### 3-2. 데이터 진입 경로
| 출처 | 경로 | 초기 상태 |
| --- | --- | --- |
| 자사 이수 | LMS 자동 조회 (입력 불필요) | 자동 분류 |
| 타기관 이수 | 지정 양식 엑셀 업로드 | 미분류 |
| 자격증 | 상담사 직접 입력 (과목 대체 / 학점 덩어리) | 확정 인정 |

- 업로드 양식 컬럼: `이수구분 · 과목명 · 학점원 · 연도-학기 · 학점 · 기관명`
- 이수구분은 양식 값 그대로, 인정 상태만 미분류

### 3-3. 시간 축 분리 원칙
- 기이수(과거) ↔ 수강 계획(미래)을 화면 상하로 분리
- 이수 시기 데이터화 시 연 42학점 한도 교차 검증 가능

### 3-4. 검증
- 자격증 모드: 이수 기준 충족 / 현장실습 배치 / 선이수 순서 / 학기당 이수학점
- 학위 모드: 총 학점 / 전공 / 교양 / 학기당 이수학점
- 전 항목 통과 시에만 발송 활성, 미충족 시 사유 입력 후 강제 발송(이력·스냅샷 표기)
- 검증 엔진 재사용: **설계=계획 채점 / 이정표=실적 채점**
