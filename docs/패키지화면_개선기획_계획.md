## 1. 현 화면 진단

### 1-1. 실제 구조 (2026-08-13 캡처)

패키지 6개 × 개강일 3개 = **CTA 18개**가 한 섹션에 평면 나열.

| 패키지명 | 배지 | 과목당 | 정가 | 최대할인가 |
|---|---|---|---|---|
| 이론 16과목 패키지 | 최대 76% | 36,400원 | 1,120,000원 | 582,400원 |
| 이론 20과목 전문학사 패키지 | 최대 77% | 평균 33,920원 | 1,280,000원 | 678,400원 |
| 이론 18과목 건강가정사 패키지 | 최대 77% | 평균 35,022원 | 1,230,000원 | 630,400원 |
| 이론+실습 17과목 (수도권반) | 최대 76% | 이론 36,400원 | 1,420,000원 | 882,400원 |
| 이론+실습 17과목 (전국반) | 최대 76% | 이론 36,400원 | 1,520,000원 | 982,400원 |
| 이론 8과목 패키지 | 최대 75% | 38,000원 | 560,000원 | 304,000원 |

개강일은 6개 카드 각각에 `[2026년2학기] 8월 14일 / 9월 4일 / 9월 17일 개강` 3행이 **동일하게 복제**되어 있음.

### 1-2. "복잡해 보이는" 원인 7가지

1. **선택 축 3개가 카드 6장에 뭉개져 있음.**
   실제로 사용자가 결정해야 하는 것은 ①목표(사회복지사만 / 전문학사 병행 / 건강가정사 병행) ②실습을 배움에서 들을지 + 권역(수도권/전국) ③분량(한 학기에 8과목 vs 16과목). 3차원 좌표를 1차원 목록으로 펼쳐놨기 때문에 사용자가 "내 좌표"를 찾을 수 없음.

2. **개강일이 상품 축과 직교하는데 카드마다 복제됨.**
   개강일은 "언제 시작하나"이지 "무엇을 사나"가 아님. 이 하나 때문에 CTA가 6개→18개로 3배가 됨. 화면 밀도의 최대 기여 요인.
   → 참고: 계열사 **배론**은 같은 6패키지 구조지만 개강일을 드롭다운으로 처리(4개 개강일, CTA 6개). 그룹 내에서도 표기가 불일치.

3. **상품명이 공급자 언어.**
   "이론 16과목", "이론 20과목 전문학사" — 학습자는 자기가 몇 과목 들어야 하는지 모르는 상태로 들어옴. 정작 `17과목 51학점 (이론 16 + 실습 1)`이라는 자격 요건은 페이지 **한참 아래** 별도 섹션에 있어서, "이론 16과목 패키지만 사면 자격증이 안 된다"는 사실이 화면상 연결되지 않음. → 오구매·CS 문의의 1차 원인으로 의심됨(Phase 0에서 검증).

4. **가격이 3중 표기인데 정작 조건이 없음.**
   `최대 76% 배지` + `과목당 36,400원` + `1,120,000원 취소선 → 582,400원`이 동시에 노출되는데, **"최대할인"을 받는 조건**은 화면 어디에도 없음. 실결제가와 다를 수 있어 신뢰를 깎고, 카드 간 비교도 방해함(어떤 카드는 "과목 당", 어떤 카드는 "과목 평균", 실습 포함 카드는 "이론 과목 당" — 분모가 제각각).

5. **비교(diff)가 불가능.**
   6장이 같은 정보 슬롯을 쓰지만 "16 vs 17 vs 18 vs 20의 차이가 정확히 어떤 과목인가"를 알 수 없음. 사용자는 숫자 차이만 보고 추론해야 함.

6. **수도권반 / 전국반이 이름만 다르고 10만원 차이.**
   무엇이 다른지(실습처 권역·교육장 위치) 카드에 설명이 없음.

7. **패키지 ↔ 단과 판단 근거가 없음.**
   바로 아래 "단과할인 이벤트"(5과목 이상 과목당 50,000원)가 별도 섹션으로 있어서, `이론 8과목 패키지 304,000원`과 `단과 8과목 400,000원`의 비교가 사용자 머릿속에서만 일어남.

### 1-3. 구조적 발견 — 카탈로그는 이미 "조합형"이다

6개 패키지는 독립 상품이 아니라 **베이스 + 애드온**임. 그리고 **할인가 기준으로는 단가가 완전히 일관됨**:

```
할인가 = 582,400 (이론 16과목)  +  24,000 × 추가과목  +  실습(수도권 300,000 / 전국 400,000)
```

| 패키지 | 계산식 | 결과 | 실제 표기가 |
|---|---|---|---|
| 이론 16과목 | 582,400 | 582,400 | 582,400 ✓ |
| 이론 20과목 전문학사 | 582,400 + 24,000×4 | 678,400 | 678,400 ✓ |
| 이론 18과목 건강가정사 | 582,400 + 24,000×2 | 630,400 | 630,400 ✓ |
| 이론+실습 17과목(수도권) | 582,400 + 300,000 | 882,400 | 882,400 ✓ |
| 이론+실습 17과목(전국) | 582,400 + 400,000 | 982,400 | 982,400 ✓ |
| 이론 8과목 | 8 × 38,000 (별도 소량 티어) | 304,000 | 304,000 ✓ |

**6종이 전부 정확히 재현됨.** 실습은 할인 없이 정가 그대로 더해지고(300,000 / 400,000), 추가 과목은 할인가 기준 **과목당 24,000원**으로 통일. 정가 쪽만 교양 40,000 / 건강가정사 55,000으로 갈리므로 표기가 지저분해 보였던 것.

즉 **6개 카드는 "16과목 베이스에 무엇을 얹느냐"의 4가지 변형 + 반쪽(8과목)** 이고, **가격 체계는 이미 조합형**임. UI가 조합 구조를 감추고 결과물만 나열하고 있어서 복잡해 보이는 것. → C안의 가장 강한 근거. (정가 산식의 불일치가 의도된 것인지는 Phase 0에서 상품팀 확인 필요.)

### 2-2. 휴사평(휴넷) 심층 — "상담 트랙 / 셀프 트랙" 분리

배움 진단 7번(패키지↔단과 판단 근거 없음)에 대한 가장 직접적인 답. 휴넷은 두 트랙을 **의도적으로 상호배타**로 만들고 각각에 다른 UI를 줌.

**트랙 A — 상담형 패키지 (카드 3장)**

| 한 줄 설명 | 상품명 | 가격 표기 |
|---|---|---|
| 건강가정사까지 한 번에! | 사회복지사2급 **더블완성패키지** | 과목당 150,000원 → 77% 기본할인 **35,000원** → 상담시 추가할인 → **??,???원** |
| 개인맞춤설계로 한 번에! | 사회복지사2급 **플랜업패키지** | 〃 75% → **37,000원** → ??,???원 |
| 부담없이 한 학기 시작 | 사회복지사2급 **스타트패키지** | 〃 74% → **39,000원** → ??,???원 |

- **상품명이 과목 수가 아니라 "상황/의도"** — 더블완성 / 플랜업 / 스타트. 그 위에 한 줄 설명을 얹어 자기 좌표를 찾게 함. 배움의 "이론 20과목 전문학사 패키지"와 정반대.
- **가격 3단 구조**: 정가 → **확정 할인가(실제 숫자)** → 조건부 추가할인(`??,???원`, "상담시"). 확정가를 먼저 보여주므로 표시가 신뢰가 유지되고, 추가할인은 조건이 명시됨.
  → 배움의 `최대 76% / 582,400원`은 이 구조에서 **맨 마지막 칸(조건부)을 조건 없이 첫 칸에 쓴 것**. 문제의 정확한 정의.
- **총액을 노출하지 않고 과목당 단가만** 노출. 배움은 1,120,000원 취소선을 보여줌.
- 각주로 조건 설명: "1:1 담당자가 상담 후 개인맞춤 설계와 최대 할인을 적용" / "결제 전 마지막 단계에서 쿠폰 적용".
- 단, `??,???원`은 다크패턴 소지가 있어 **그대로 베낄 대상은 아님**(→ 2-3 메가원격이 더 나은 해법).

**트랙 B — 셀프 단과 (다이렉트 핫딜)**

- `셀프 학습설계시 80% 할인 · 150,000원 → 과목당 29,900원`
- 유의사항에 명시: **"다이렉트 핫딜 수강료로 수강신청하신 회원분은 추후 학습설계 관련 상담을 받으실 수 없습니다."** — 두 트랙의 교환 조건(가격 vs 설계 지원)을 대놓고 규정
- 과목 카드 24개, 각각에 배지: `마감임박` / `민간자격증 발급 가능` / `다다익선` / `건`(건강가정사) / `교`(교양)
  → **과목 단위 태깅**. 사용자가 스스로 조합할 수 있는 최소 정보를 제공. 배움은 과목 목록 자체가 화면에 없고 하단 표에 텍스트로만 있음
- `사회복지현장실습 600,000원`(할인 없음), `학교사회복지론 150,000원`(할인 없음, `마감`) — 상태·예외를 목록 안에서 그대로 표현

**개강일 처리**

- 상단 고정 바: `8월 19일 개강반 모집 중! 마감까지 05day 10:56:01` + `마감전 수강신청 →`
- 단과 목록에만 개강일 **탭 3개**(8/19, 9/09, 11/11), 탭 아래에 `신청기간 / 학습기간 / 학점인정신청 / 학위취득` **4개 날짜**
- → 개강일이 상품 카드에서 완전히 빠짐. **CTA 복제 없음.** 게다가 "언제 자격증이 나오나"를 개강일 선택의 판단 기준으로 제공(배움은 개강일만 있음)

**그 외** — FAQ 아코디언 7문항, 장바구니, `전문대학 이상 / 고등학교 졸업자` 이수학점·소요기간 비교표.

### 2-3. 메가원격 심층 — 가장 압축된 카드

배움과 **카탈로그 논리가 사실상 같은데**(이론 베이스 + 실습 애드온) 화면은 카드 3장으로 끝남.

| 구성 라벨 | 상품명 | 정가 | 판매가 | 보조 |
|---|---|---|---|---|
| 이론 16과목 + 실습 1과목 | **한방 풀패키지** | 1,084,000원 | **867,000원** | (이론 과목당 약 35,400원) |
| 이론 16과목 | **이론 완성 특가 패키지** | 784,000원 | **627,000원** | (이론 과목당 약 39,200원) |
| 전국단위 | **사회복지 현장 실습** | 500,000원 | **300,000원** | — |

배울 점 5가지:

1. **구성을 상품명 위에 라벨로 분리.** `이론 16과목 + 실습 1과목`(작게) / `한방 풀패키지`(크게). 무엇이 들어있는지와 어떻게 부르는지를 분리해서, 마케팅 네이밍을 쓰면서도 구성이 즉시 읽힘. 배움은 둘을 한 문자열에 욱여넣어("이론 20과목 전문학사 패키지") 둘 다 잃음.
2. **가격 슬롯이 1개.** 정가 취소선 → 판매가, 괄호로 과목당 환산. **할인율 배지 없음**(히어로에 `77% OFF` 한 번만). 배움은 배지+단가+정가+할인가 4개가 카드마다 반복.
3. **CTA를 2개로 명시 분리** — `추가 할인 신청`(파랑, 상담 유입) vs `패키지 신청하기`(검정, 즉시 결제). 휴넷과 같은 이중 트랙이지만 **가격을 가리지 않고** 분기함. → 배움 "최대할인" 문제의 가장 깔끔한 해법.
4. **개강일이 페이지에 아예 없음.** 마감일(`2026년 8월 26일(수) 마감`) 하나만 히어로에. 개강반 선택은 결제 플로우로 넘김.
5. **실습을 단품 카드로 병렬 배치** — 3번 카드는 `단과 신청하기`. 패키지에 실습을 넣을지 말지를 카드 3장 비교로 즉시 판단 가능. 배움은 수도권/전국을 별도 패키지 2장으로 분리해 오히려 카드 수만 늘림.

> 참고: 메가원격 GNB에 **`메가 다이렉트 학습설계` / `학습설계 예상결과보기`** 메뉴가 있음 — 셀프 학습설계 도구를 이미 서비스 중. 이 저장소의 `learning-plan/builder.html`과 직접 비교할 경쟁 레퍼런스이므로, 학습설계 툴 기획 시 별도 조사 권장.

### 2-4. 중앙사이버 심층 — 요건을 "채울 칸"으로 보여주기

**카드 3장** (개강반은 상단 스티키 바 1개 + 전역 카운트다운 `20일 10시간 46분 남았습니다`)

| 구성 라벨 | 상품명 | 가격 |
|---|---|---|
| 이론 16과목 | 사회복지사 2급 이론 **올인원(all-in-one) 패키지** | 과목당 **33,000원** · `최대 80% 파격할인` · `💬상담 시 추가할인` |
| 이론 16과목 + 실습 1과목 | 사회복지사 2급 실습 **올인원(all-in-one) 패키지** | 〃 |
| 전국실습가능(도서산간 불가) · 온라인실습신청 · 실습처 리스트 제공 | **사회복지현장실습** | 수도권 **300,000원** / 비수도권 **348,000원** |

**배울 점**

1. **실습 권역을 카드 1장 안에서 두 가격으로 병기.** 배움은 `수도권반`·`전국반`을 **별도 패키지 2장**으로 만들어 카드 수를 6개까지 늘렸음. 중앙은 실습 단품 카드 하나에 `수도권 300,000 / 비수도권 348,000`을 나란히 씀. → **배움의 6개 중 1개는 카드가 아니라 가격 한 줄이면 됨.**
2. **건강가정사를 상품이 아니라 설명으로 처리.** 별도 섹션에 `3과목 추가 수강으로 자격증이 하나 더!`. 배움은 이걸 "이론 18과목 건강가정사 패키지"라는 **7번째 상품**으로 만들어 또 카드 하나를 씀. → **배움의 6개 중 또 1개도 설명으로 대체 가능.**
3. **요건을 진행률 게이지로.** 가장 인상적인 부분:
   ```
   필수과목  온라인 이론 9과목        0 / 9과목
   사회복지현장실습 1과목
       실습 세미나 30시간            0 / 30시간
       사회복지현장실습 160시간      0 / 160시간
   선택과목  온라인 이론 7과목        0 / 7과목
   필요 학점                          51학점
   ```
   "17과목 51학점"이라는 문장 대신 **비어 있는 칸**을 보여줌. 자기가 무엇을 얼마나 채워야 하는지가 즉시 읽힘.
   → 이 저장소 `learning-plan/builder.html`의 기이수 현황(`ihList()`)·영역별 충족 표시와 **정확히 같은 개념**. 랜딩과 학습설계 툴이 같은 시각 언어를 쓸 수 있는 지점.
4. **설명 부담을 영상으로 오프로드** — `글로 된 설명이 어렵다면 쥬쌤이 쉽게 알려드립니다 → 쥬쌤TV`.
5. 자사 개설 과목을 표에서 **굵게** 표기(여기스터디는 보라색). 배움은 전과목 개설이라 불필요할 수 있으나, "전과목 개설"이 강점이라면 오히려 대비로 보여줄 수 있음.

**베끼지 말 것 — 중앙의 약점**

- 카드 3장의 `✓ 혜택 4줄`이 **전부 동일**함(다음학기 자리 확보 / 민간자격증 / 모바일 출석). 카드에 **차이(diff)가 아니라 공통 혜택**을 반복하고 있어서, 3장을 비교할 근거가 첫 줄(구성 라벨)밖에 없음. → **공통 혜택은 카드 밖 공용 영역으로 빼야 함.**
- 이론 올인원과 실습 올인원이 **둘 다 과목당 33,000원** — 가격이 변별 정보로 기능하지 않음. 배움의 75~77% 배지와 같은 문제.
- 최종학력 분기는 화면에 없고 전부 상담으로 넘김("최종학력에 따라 수강해야 할 과목 수와 학습 기간이 전부 다릅니다 → 1:1 맞춤 학습설계 제공").

### 2-5. 메가원격 `메가 다이렉트 학습설계` — B안의 완성형 선례

[https://www.caedu.co.kr/EVENT/studyplan/studyplan.aspx](https://www.caedu.co.kr/EVENT/studyplan/studyplan.aspx) — 셀프 학습설계 진단 도구가 **이미 서비스 중**. B안 셀렉터의 확장판이자, 이 저장소 `learning-plan/builder.html`의 직접 경쟁 서비스.

**7단계 위저드**

```
STEP 1  학습설계 유의사항
STEP 2  목표선택
STEP 3  최종학력 선택
STEP 4  학점이수내역 선택
STEP 5  학점이수내역 유의사항 안내
STEP 6  학습설계 결과보기
STEP 7  추천상품 보기        ← 진단이 곧 상품 추천 퍼널
```

- **STEP 2~4가 정확히 B안의 셀렉터 3문항**(목표 / 최종학력 / 기이수 학점)이고, 마지막이 **추천상품 보기**. 진단 → 결과 → 상품이 한 흐름으로 연결됨. B안이 실현 가능하다는 업계 선례.
- **완전 자동이 아님** — 유의사항에 "신청 후 업무일 기준 1일 이내 답변을 확인할 수 있습니다 … 답변완료 시 문자 및 이메일이 발송됩니다". 즉 **반자동(상담사 검수 후 발송)**. 배움도 "즉시 추천 vs 검수 후 발송" 중 정책 선택이 필요.
- **면책 문안이 이미 정형화되어 있음** — 셀프 진단 도구를 만들 때 그대로 참고할 문장들:
  - "증명서 확인 없이 학습자의 입력사항만으로 진행됩니다"
  - "입력사항과 실제취득학점이 다를 경우, 학습설계 결과가 다를 수 있습니다"
  - "잘못된 입력으로 인해 학습자에게 불이익이 발생할 수 있으며, 해당 책임은 본인에게 있습니다"
  - "'학점인정신청'과는 별도의 절차입니다. 학점인정신청은 국가평생교육진흥원을 통해서 진행해야만 합니다"
- STEP 1 이후는 **로그인 필요**로 확인하지 못함. 결과 화면(STEP 6·7)의 실제 UI와 추천 로직은 **미조사** — 계정 확보 후 별도 조사 필요.

> 조사 메모: 휴사평의 `셀프 학습설계(다이렉트 핫딜)`, 여기스터디의 `나만의 맞춤 이수계획표 무료진단`도 같은 계열. **5개사 중 3개사가 이미 셀프 진단 도구를 운영 중**이며, 배움만 상담 인입 폼(이름·휴대폰·과정)뿐임.

### 2-6. 업계 5개사 비교 — 한눈에

| | 배움(현행) | 여기스터디 | 중앙사이버 | 휴사평 | 메가원격 |
|---|---|---|---|---|---|
| 카드 수 | **6** | 0 (학력 CTA 2개) | 3 | 3 (+단과 목록) | **3** |
| 섹션 내 CTA 수 | **18** | 2 | 3 | 3 (+상단 1) | 6 (카드당 2) |
| 개강일 위치 | **카드 안 3행 복제** | 상단 독립 블록 | 상단 스티키 바 | 상단 바 + 목록 탭 | **없음(마감일만)** |
| 상품명 | 과목 수 | 학력 | 이론/실습/실습단품 | 상황(스타트·플랜업·더블완성) | 마케팅명 + 구성 라벨 |

| 실습 권역 처리 | **패키지 2장으로 분리** | — | 카드 1장 안에 2가격 병기 | 단과 목록 내 1건 | 단품 카드 1장 |

| 선택 가이드 | 없음 | 학력 분기 + 무료진단 | 없음(상담으로) | 트랙 분리(상담/셀프) | CTA 분리 + **7단계 진단 도구** |
| 자격 요건 노출 | 하단 별도 섹션 | 학기별 플랜 표 | **진행률 게이지** | 하단 표 + FAQ 7문항 | 하단 |
| 셀프 진단 도구 | **없음** | 무료진단 | 없음 | 셀프 학습설계 | 메가 다이렉트 학습설계 |

**배움은 모든 열에서 최댓값** — 카드도, CTA도, 가격 슬롯도 가장 많고, 선택 가이드와 진단 도구만 없음. "복잡해 보인다"는 인상은 정확한 관찰임.

특히 **카드 6장 중 2장은 다른 회사들이 카드로 만들지 않는 것**임:
- `이론+실습 17과목(수도권반)` / `(전국반)` → 중앙처럼 **한 카드 안 두 가격**이면 1장 절약
- `이론 18과목 건강가정사 패키지` → 중앙처럼 **설명 섹션**이면 1장 절약

즉 상품 데이터를 하나도 안 바꿔도 **카드 표현만으로 6 → 4장**이 가능. A안의 실질 상한이 여기서 나옴.

### 2-7. 공통 패턴 — 5개사 중 3개 이상이 하는 것

1. 개강일을 **상품 카드 밖으로** 뺀다 (여기스터디·중앙사이버·휴사평·메가원격 = **4/4**)
2. 카드는 **3장 이하** (중앙사이버·휴사평·메가원격 = 3/3, 여기스터디는 0장)
3. 카드 내 가격은 **하나의 지표**로 압축 (중앙사이버·메가원격)
4. 상품명 또는 그 위 한 줄에 **"누구를 위한 것인지"** 를 쓴다 (여기스터디·휴사평·메가원격)
5. **상담 유입 경로를 CTA/트랙으로 명시 분리** (휴사평·메가원격)
6. **셀프 진단 도구**를 운영한다 (여기스터디·휴사평·메가원격 = **3/5**) — 배움만 이름·휴대폰 상담 폼뿐

### 2-8. 일반 UX 패턴 (요금제/플랜 선택)

[Smashing Magazine — Designing Better Pricing Page](https://www.smashingmagazine.com/2022/07/designing-better-pricing-page/) / [Smart Interface Design Patterns — Pricing Plans UX](https://smart-interface-design-patterns.com/articles/pricing-plans/) 등에서 반복적으로 확인되는 원칙:

- **3~4개 티어**가 상한. 그 이상은 선택 마비 → 이탈.
- 각 플랜에 **"이런 분께" 한 줄(best for)** 을 붙여 자기 좌표를 즉시 찾게 함.
- **추천 플랜 1개를 시각적으로 하이라이트**해 기본값을 제공.
- 플랜 수가 많으면 **니즈 셀렉터/세그먼트 토글**로 먼저 좁힌 뒤 가격을 보여줌.
- 상세 차이는 기본 화면에 다 펼치지 말고 **아코디언·툴팁·2개 비교 모드**(Dropbox 방식)로 접어둠.
- 모바일에서는 표 가로 스크롤 금지, **한 번에 한 속성씩 보여주는 단계형**으로 전환.
- 신뢰 요소(보증·후기·환불 규정)는 푸터가 아니라 **CTA 근처**에.

## 3. 브레인스토밍 — 개선 방향 3안

세 안은 배타적이지 않고 **A ⊂ B ⊂ C**로 누적 가능. 기획안에서는 3안을 모두 제시하되 **B안을 권고안**으로 잡는 것을 제안.

### A안 — 최소 개입 (구조 유지, 표기 정리) · "메가원격형"

메가원격 카드를 그대로 벤치마크. 상품 6개는 건드리지 않고 **카드 표현만** 바꿈.

- 개강일을 카드 밖으로 → 섹션 상단 독립 바 또는 카드 내 드롭다운. **CTA 18 → 6**
- 카드 구조를 `구성 라벨(작게) / 상품명(크게) / 정가 취소선 → 판매가 / (과목당 환산) / CTA`로 통일
  - 예: `이론 16과목 + 실습 1과목(수도권)` / **실습까지 한 번에 패키지** / ~~1,420,000원~~ → **882,400원**
- **할인율 배지 6개 제거**, 히어로에 1회만 (75~77%로 변별력이 없어 정보가 아니라 노이즈)
- CTA를 `상담받고 추가할인` / `바로 신청`으로 분리 → "최대할인" 조건 문제를 문구 대신 **동선으로** 해결
- **카드 6 → 4장** (2-6의 발견): 실습 수도권/전국은 **한 카드 안 두 가격**으로 병합(중앙사이버형), 건강가정사는 카드 대신 **설명 섹션**으로 이동(`2과목만 더 들으면 자격증이 하나 더`)
- **카드 공통 혜택은 카드 밖 공용 영역으로.** 카드 안에는 **차이만** 남김 (중앙사이버가 실패한 지점)
- 자격 요건(17과목 51학점)을 패키지 섹션 **바로 위**로 옮기고, 문장 대신 **진행률 게이지**로 표현 (중앙사이버형)
  ```
  필수 이론 9과목  0/9   ·  선택 이론 7과목  0/7  ·  현장실습 160시간  0/160   →  51학점
  ```

투입 최소·리스크 최저. 개발 없이 퍼블리싱만으로 가능한 범위가 대부분. 다만 선택 축이 뒤섞인 근본 문제는 남음.

### B안 — 조건 선택형 (권고) · "여기스터디 + 휴사평형"

A안 위에, 6개를 다 보여주기 전에 **좁혀주는 단계**를 얹음.

- 섹션 최상단에 **2~3문항 셀렉터**: `최종학력(고졸 / 전문대졸 이상)` × `목표(자격증만 / 전문학사 병행 / 건강가정사 병행)` × `실습을 배움에서(예-수도권 / 예-전국 / 아니오)`
- 입력 결과 → **추천 패키지 1개를 크게 + 대안 1~2개를 작게**. 나머지는 `전체 패키지 보기`로 접음
- 개강일은 섹션 상단 **독립 바** 1개. 휴사평처럼 `신청기간 / 학습기간 / 학점인정신청 / 학위취득` 4개 시점을 함께 표기해 **"언제 자격증이 나오나"를 선택 기준으로** 제공
- 추천 결과 하단에 **학기별 이수 플랜 미리보기**(1학기 8과목 → 2학기 6과목 → 3학기 3과목)를 붙여 "왜 이 패키지인지"를 설명
- **패키지 ↔ 단과 트랙 분리**(휴사평 모델): "상담받고 맞춤 설계" vs "혼자 골라서 더 싸게". 현재 단과할인 이벤트가 패키지 아래에 무맥락으로 놓인 문제를 구조로 해결
- FAQ 아코디언을 섹션 하단에 (휴사평 7문항 참고) — 상담 인입 전 자가 해소

기존 6개 상품 그대로 두고 **탐색 경로만 바꾸는** 안이라 상품·정산 시스템 변경이 없음. 이게 핵심 장점.

**선례:** 메가원격 `메가 다이렉트 학습설계`가 이 구조를 7단계 위저드로 이미 구현(2-5). 배움 B안은 그 **경량판**(랜딩 안에 들어가는 2~3문항)으로 잡고, 더 깊은 진단이 필요한 사용자는 상담 또는 별도 학습설계 툴(`learning-plan/builder.html`)로 넘기는 2단 구성을 제안.

### C안 — 모듈 구성형 (구조 재설계)

- 1-3의 발견대로 **베이스(이론 16과목) + 애드온(실습 권역 / 전문학사 교양 / 건강가정사)** 구성기로 전환
- 사용자가 체크박스로 얹으면 과목 수·금액·이수 학기가 실시간 갱신
- 카드 6장이 사라지고 **화면 1개**가 됨
- 전제 조건: **과목 단위 태깅**이 필요함 — 휴사평의 `건`(건강가정사) / `교`(교양) / `민간자격증` 배지처럼, 각 과목이 어느 목표에 쓰이는지를 데이터로 갖고 있어야 조합이 성립. 이 태깅은 A·B안에서도 과목 목록 노출에 쓸 수 있어 **선행 투자로 정당화 가능**
- 이 저장소의 `learning-plan/builder.html`(학습설계 툴)과 **도메인 모델을 공유**할 수 있음 — 과목/영역/학점 구조가 이미 동일
- 경쟁사 선례 있음: 메가원격 `메가 다이렉트 학습설계`, 휴사평 `셀프 학습설계(다이렉트 핫딜)`

가장 깔끔하지만 상품 등록 체계·결제·정산·마케팅 소재까지 영향. 중장기안으로 제시.

### 안별 비교

| | A안 | B안 (권고) | C안 |
|---|---|---|---|
| 카드 수 | 6 | 1~3 (+접힌 6) | 0 (구성기 1개) |
| CTA 수 | 6~12 | 2~4 | 1 |
| 상품 데이터 변경 | 없음 | 없음 | **필요** (과목 태깅·조합 상품) |
| 결제/정산 영향 | 없음 | 없음 | **있음** |
| 근본 문제(선택 축) 해소 | ✕ | ○ | ◎ |
| 예상 기간 | 3~5일 | 2~3주 | 별도 과제 |

## 4-1. 개강일 배치 — 설계 판단 정정 (2026-08-13)

**초기 시안은 개강일을 상품 위 독립 선택기로 올렸으나, 이는 잘못된 처방이었음.** 진단은 "개강일이 카드마다 3행씩 복제되어 CTA가 18개"였고 이는 **중복** 문제인데, 처방이 개강일을 **승격**시키는 것이 되어 중복 문제를 위계 문제로 치환해 버렸음.

**위계는 현행이 맞다 — 패키지가 상위, 개강일이 하위.** 없앨 것은 반복뿐.

### 레퍼런스 재검토 — 상단 선택기로 둔 곳은 없음

앞서 "4/4가 개강일을 카드 밖으로 뺐다"고 정리했으나, **카드 밖으로 뺀 것**과 **상품 위 선택기로 올린 것**은 다름:

| 사이트 | 실제 처리 | 성격 |
|---|---|---|
| 메가원격 | 페이지에 개강일 **없음** (마감일만) | — |
| 중앙사이버 | 얇은 스티키 바 | 공지 |
| 휴사평 | 카운트다운 바 + 개강일 탭은 **단과 목록에만**(패키지엔 없음) | 긴급성 |
| 여기스터디 | 상단 블록이지만 "9월 5일 개강이면 최단기 1년 1개월" | 설득 |

**5개사 중 개강일을 상품 위 선택기로 둔 곳은 0곳.**

### 결정적 근거 — 가짜 필터

상단 선택기는 "고르면 아래가 바뀐다"는 신호를 주지만 **바뀌지 않음**. 개강반 3개는 **상품·가격·정원이 전부 동일**(2026-08-13 확인). 아무것도 거르지 않는 필터가 최상단을 차지하고, 사용자는 관심 없는 질문에 먼저 답하게 됨. 게다가 3개가 8/14·9/4·9/17로 **한 달 안쪽, 전부 같은 2026년 2학기**라 저관여 선택임.

### 개강일의 세 역할 — 분리해서 배치

| 역할 | 내용 | 배치 |
|---|---|---|
| 긴급성 | "모집 중 · 신청 마감" | 상단 **얇은 공지 띠** (중앙사이버·휴사평) |
| 설득 | "지금 시작하면 2027년 2월 자격증" | 히어로 카피 (여기스터디) |
| 선택 | 실제 등록할 개강반 | **신청하는 순간** — 카드 내 드롭다운 또는 결제 플로우 |

초기 시안은 셋을 한 덩어리 카드로 묶어 상단에 올린 것이 문제. **선택 역할만 카드 안으로 내리면 해결됨.**

### 권고 및 시안 반영

**카드당 개강일 드롭다운 1개.** 위계는 현행 유지, 3행 반복만 제거 → CTA는 카드 수만큼. 계열사 **배론이 이미 쓰는 방식**이라 그룹 내 정합성 명분도 있음. 상단에는 선택기 대신 얇은 공지 띠(`2026년 2학기 모집 중 · 가장 빠른 개강 8월 14일 · 신청 ~8월 13일 · 다음 개강 9월 4일 · 9월 17일`). `신청기간 / 학습기간 / 학점인정 / 자격증 수령` 4개 시점은 드롭다운 아래 한 줄로 유지.

와이어프레임에 **`개강일 배치` 비교 토글**(상단 선택기 ↔ 카드 내 드롭다운)을 추가해 두 배치를 직접 비교할 수 있게 함. 기본값은 권고안(카드 내 드롭다운). A·B·C 세 시안에 공통 적용되며, 상단 선택기 모드에서는 "가짜 필터" 경고가 함께 노출됨.

## 5. 결정이 필요한 열린 질문

기획 착수 전에 답이 있어야 범위가 고정되는 항목:

1. **적용 범위** — 사회복지사 랜딩 1개만 개선할 것인가, 아니면 보육교사·한국어교원·평생교육사 등 **전 과정 랜딩의 공통 템플릿**으로 설계할 것인가? (구조가 동일할 것으로 보여 후자가 효율적이나 이해관계자가 늘어남)
2. ~~**개강일 축** — 3개 개강반을 화면에 계속 다 노출해야 하는 영업상 이유가 있는가?~~ → **확인 완료(2026-08-13)**: 개강반 3개는 **상품·가격·정원이 전부 동일**. 결론은 아래 §6.
3. **랜딩 vs 신청 플로우** — 이 저장소의 `enrollment/` 수강신청 개편 시안과 **한 흐름으로 이어서** 설계할 것인가, 랜딩 섹션만 독립적으로 볼 것인가?
4. **산출물 형태** — HTML 와이어프레임까지 만들 것인가(Phase 3), 문서 + 3안 설명만으로 충분한가?
5. **"최대할인" 표기** — 마케팅 요구사항으로 고정인가, 표기 원칙 재설계 대상에 포함 가능한가?
   - 대안 3가지: ①메가원격형(확정 판매가만 노출 + `추가 할인 신청` CTA 분리) ②휴사평형(정가→확정할인가→`??,???원` 상담시 추가) ③현행 유지(최대할인가를 표시가로). **①을 권고** — 표시가 신뢰를 지키면서 상담 인입 동선도 확보되고, `??,???원`의 다크패턴 소지도 없음
6. **패키지/단과 트랙 분리 여부** — 휴사평은 "핫딜로 신청하면 학습설계 상담을 받을 수 없다"고 교환 조건을 명시함. 배움도 상담 리소스와 셀프 구매를 이 정도로 갈라놓을 것인가, 아니면 모든 구매자에게 상담을 유지할 것인가? **이 답에 따라 B안의 화면 구조가 달라짐**
7. **과목 단위 태깅 보유 여부** — 각 과목이 `건강가정사 / 전문학사 교양 / 민간자격증 / 실습선이수` 중 어디에 해당하는지 데이터로 갖고 있는가? 없다면 C안은 물론 A·B안의 과목 목록 노출도 불가
8. **상품 6개를 4개로 줄일 수 있는가** — 2-6의 발견대로 `실습 수도권반/전국반`을 한 카드 두 가격으로, `건강가정사 패키지`를 설명 섹션으로 대체하면 **화면상 카드는 4장**이 됨. 상품 자체를 통폐합할 것인가(상품팀 결정), 아니면 상품은 6개로 두고 **화면에서만 묶을 것인가**(퍼블리싱 범위)?
9. **셀프 진단 도구를 만들 것인가** — 5개사 중 3개사가 운영 중이고 배움만 없음. 만든다면 ①즉시 자동 추천 ②메가원격형 반자동(1일 내 상담사 검수 후 문자·이메일) 중 어느 쪽인가? 후자는 상담 리소스가 필요하지만 오안내 리스크가 낮음
10. **`learning-plan/builder.html`과의 관계** — 랜딩 셀렉터(B안)와 학습설계 툴을 **같은 도메인 모델·같은 시각 언어**(중앙사이버형 진행률 게이지)로 갈 것인가? 그렇다면 두 과제를 함께 설계해야 함
